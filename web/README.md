# VibeStream Web Preview

A responsive, high-fidelity web version of the VibeStream music pipeline to test the UI/UX, real-time search, streaming, and offline download capabilities directly in your browser.

## 🚀 Quick Start

### Option 1: Python Local Server (Recommended)
From PowerShell / Terminal:
```bash
cd "c:\Users\jaiad\Personal_Work_Related\Personal Projects\vibestream_web"
python server.py
```
This automatically launches `http://localhost:5173` in your default browser.

### Option 2: Direct File Open
Simply double-click [`index.html`](index.html) to open it in Chrome, Edge, or Firefox.

---

## 🎨 UI/UX Highlights

* **📱 Phone View vs. 🖥️ Full View:** Switch seamlessly between a mobile phone mockup frame (to see exactly how it feels on an Android device) and an expansive full-screen mode.
* **Instant Playback & Scrubber:** Click any song to start playback. Includes a docked mini-player at the bottom and an expandable full-screen player sheet with scrubber, ±10s skips, and canvas visualizer.
* **Live Search & Fallback:** Search YouTube for any song or artist, or click the quick genre tags (Lo-Fi, Synthwave, Acoustic, High Energy).
* **💾 Offline Download Pipeline:** Click the download icon on any song to save the audio file to your local device. View all saved songs in the **Offline Downloads** tab.
